# Smart Document Search

Smart Document Search is an ASP.NET Core MVC application that allows users to upload documents, extract their text, and search for words or phrases inside them. It supports PDF, Word and text files and displays matching content with page numbers and highlighted search terms.

## Features

* Upload PDF, DOCX and TXT documents
* Validate file type and file size
* Store uploaded files with unique names
* Extract text automatically during upload
* Extract PDF content page-by-page
* Save document information and extracted text in SQL Server
* View extracted text inside the application
* Search across all uploaded documents
* Search inside an individual document
* Highlight matching words and phrases
* Display the number of matches
* Display matching PDF page numbers
* Download original documents
* Delete documents and their extracted content
* Save search activity in search history

| Text file      | `.txt`    | C# file handling  |

## How It Works

1. The user selects a PDF, DOCX or TXT file.
2. The application validates its type and size.
3. The file is saved in the `Uploads` folder with a unique name.
4. The appropriate service extracts its text.
5. Document information is saved in the `Documents` table.
6. Extracted text is saved in the `DocumentContents` table.
7. The user can search across all documents or within one selected document.
8. Matching words are highlighted, along with their page numbers and occurrence counts.

## Database Tables

### Documents

Stores information about uploaded files.

| Column             | Purpose                                      |
| ------------------ | -------------------------------------------- |
| `DocumentId`       | Primary key                                  |
| `OriginalFileName` | Original uploaded filename                   |
| `StoredFileName`   | Unique filename generated by the application |
| `FilePath`         | Physical storage location                    |
| `FileType`         | File extension                               |
| `FileSize`         | File size in bytes                           |
| `UploadedAt`       | Upload date and time                         |

### DocumentContents

Stores text extracted from documents.

| Column              | Purpose                              |
| ------------------- | ------------------------------------ |
| `DocumentContentId` | Primary key                          |
| `DocumentId`        | Foreign key connected to `Documents` |
| `PageNumber`        | PDF page number                      |
| `ExtractedText`     | Text extracted from the document     |

### SearchHistories

Stores previous search activity.

| Column            | Purpose                     |
| ----------------- | --------------------------- |
| `SearchHistoryId` | Primary key                 |
| `SearchTerm`      | Searched word or phrase     |
| `ResultCount`     | Number of occurrences found |
| `SearchedAt`      | Search date and time        |

## Database Relationship

```text
Documents
    |
    | One-to-Many
    |
DocumentContents
```

One document can contain multiple extracted-content records. For PDF files, each readable page is stored as a separate record.

## Getting Started

### Prerequisites

Make sure the following software is installed:

* Visual Studio
* .NET 10 SDK
* SQL Server
* SQL Server Management Studio

### 1. Clone the repository

```bash
git clone <your-repository-url>
```

Open the solution in Visual Studio.

### 2. Configure the database

Update the connection string in `appsettings.json`:

```json
{
  "ConnectionStrings": {
    "DefaultConnection": "Server=YOUR-SERVER-NAME;Database=YOURDB;Trusted_Connection=True;TrustServerCertificate=True;"
  }
}
```

Replace the server name with your SQL Server instance if required.

For SQL Server Express, you may need:

```json
{
  "ConnectionStrings": {
    "DefaultConnection": "Server=.\\SQLEXPRESS;Database=YOURDB;Trusted_Connection=True;TrustServerCertificate=True;"
  }
}
```

### 3. Create the database tables

Open Package Manager Console and run:

```powershell
Add-Migration InitialCreate
Update-Database
```

### 4. Run the project

Press:

```text
Ctrl + F5
```

The application will open the Documents page.

## Search Options

### Global Search

Global search checks the extracted text of every uploaded document and displays:

* Document name
* Matching page number
* Text surrounding the match
* Number of occurrences
* Highlighted search term

### Document-Specific Search

After opening **View Text**, the user can search only inside the selected document. The application highlights every occurrence and automatically moves to the first match.

## File Validation

The upload module currently accepts:

```text
.pdf
.docx
.txt
```

The maximum allowed file size is:

```text
10 MB
```

Files are assigned unique names using `Guid` to prevent files with identical names from overwriting each other.

## Important Limitation

PdfPig extracts text from text-based PDFs. It cannot extract text from scanned PDFs that contain only images.

```text
Selectable PDF text → Supported
Scanned image PDF   → OCR required
```

OCR support using Tesseract can be added as a future enhancement.
